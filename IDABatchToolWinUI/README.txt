IDA BATCH TOOL (WinUI) — переносимая сборка
============================================

Запуск: IDABatchTool.exe (в корне этой папки).

ВАЖНО: не удаляйте и не разделяйте содержимое папки app\ — в ней находится
приложение и все его компоненты. Архив распаковывать целиком.

ТРЕБОВАНИЯ К СИСТЕМЕ
--------------------
Обязательно:
  - Windows 10 (1809+) или Windows 11, 64-разрядная
  - IDA Pro 9.x — пакетный анализ (idat.exe)
  - BinExport 12 (плагин IDA) — для режима сравнения
  - BinDiff 8 (standalone bindiff.exe) — для режима сравнения;
    в этой поставке лежит в корне, альтернативно — путь в config.yaml
  - Python 3.10+ с пакетами jinja2 и requests — генерация HTML-отчётов
    и документация системных функций (СФ)

Опционально:
  - 7-Zip — только для распаковки .dmg (APK/IPA распаковываются без него)
  - Node.js 18+ (npx) — только резервный поиск документации MS Learn
    (основной путь — прямой запрос к learn.microsoft.com, Node не нужен)

НАСТРОЙКА
---------
Пути к утилитам: вкладка «Конфигурация» в приложении или config.yaml
(ключи ida.executable и bindiff.executable). Программа сама ищет IDA и
BinDiff в типовых местах установки.

Портативные утилиты можно встроить в поставку:
  app\Tools\Python\   — pythonw.exe + site-packages (jinja2, requests)
  app\Tools\7-Zip\    — 7z.exe
В этом случае установка Python и 7-Zip в систему не требуется.

РЕЗУЛЬТАТЫ РАБОТЫ
-----------------
Отчёты создаются внутри указанных рабочих папок:
  IDAReports\  — общий анализ
  SFAReports\  — анализ системных функций
  DiffResults\ — сравнение (отчёты в DiffResults\Reports)

Диагностика: при нештатном завершении рядом с приложением появляется
app\app-crash.log — пришлите его содержимое при обращении.

Версия сборки: см. version.txt
