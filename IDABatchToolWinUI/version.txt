IDA BATCH TOOL (WinUI) — журнал версий сборки
==============================================
Формат записи: версия / дата / что изменилось.
Версия в свойствах exe должна совпадать с последней записью
(IDABatchToolWinUI.csproj: Version / FileVersion, make-portable.ps1: лончер).

1.1.0.0 / 2026-10-05
  Добавлено:
  - проверка Python-окружения при запуске: если интерпретатор или пакеты
    jinja2/requests не найдены, появляется окно со списком отсутствующего
    и предложением автоматической установки; при полном окружении ничего
    не показывается
  - install-prereqs.ps1 в корне поставки: скачивает встроенный Python и
    ставит пакеты в app\Tools\Python (без прав администратора)
  - имя архива поставки теперь с версией: IDABatchToolWinUI-<версия>.zip
  - make-portable.ps1 встраивает Tools\Python из проекта, если он есть

1.0.0.0 / 2026-10-05
  Первая переносимая сборка.

  Исправлено:
  - краш окна при развороте на весь экран и пустая таблица пар на вкладке
    «Сравнение» (причина: ReadyToRun и тримминг в Release-публикации ломали
    WinRT-проецирование; отключены в csproj)
  - иконка приложения в опубликованной сборке (папка Assets не копировалась
    в publish)
  - на машине без .NET приложение требовало его установки: публикация
    выходила без рантайма .NET; сборка теперь самодостаточная
    (SelfContained=true, рантайм внутри app\)

  Добавлено:
  - переносимая поставка с чистым корнем: IDABatchTool.exe (лончер) + app\
    со всем содержимым; сборка — make-portable.ps1
  - bindiff.exe в корне поставки; поиск утилит в корне и внутри app\
  - app-crash.log — журнал необработанных исключений рядом с приложением
