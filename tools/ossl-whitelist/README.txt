ViPNet OSSL — белый перечень по таблицам импорта
================================================

Утилита пакета IDA Batch Tool. Проходит по готовым базам IDA (.i64/.idb),
читает ТОЛЬКО таблицы импорта, объединяет функции из всех баз, убирает повторы
и формирует HTML-отчёт с двумя перечнями:

  1. белые функции ViPNet OSSL — есть в справочнике функций ViPNet OSSL 5.6;
  2. функции OpenSSL 1.1.1w вне белого перечня — требуют дополнительного
     тематического исследования.

ЗАПУСК
------
  start_ossl_whitelist.bat            — графический интерфейс (без консоли)
  python vipnet_ossl_whitelist.py     — то же из консоли

В окне указываются:
  * каталог с базами .i64/.idb (обход рекурсивный);
  * путь к HTML-отчёту;
  * idat.exe/idat64.exe — нужен только для баз без готового .export.json
    (определяется автоматически: config.yaml приложения, Program Files, PATH);
  * число потоков IDA и признак «игнорировать готовые .export.json».

Пакетный режим:
  python vipnet_ossl_whitelist.py <каталог> --out report.html
  python vipnet_ossl_whitelist.py <каталог> --out report.html --force-ida --jobs 6
  python vipnet_ossl_whitelist.py --self-test

ОТКУДА БЕРУТСЯ ИМПОРТЫ
----------------------
  1. Если рядом с базой есть <база>.export.json (артефакт фазы «Анализ ПО»),
     импорты берутся из него — IDA не запускается.
  2. Иначе база копируется во временный каталог и открывается в IDA лёгким
     скриптом, который выгружает только таблицу импорта. Оригинальная база
     НЕ изменяется; временная копия удаляется.

СЛОВАРИ В СКРИПТЕ
-----------------
  OSSL_API  — 4893 экспорта собранных libcrypto-1_1.dll (4398) и
              libssl-1_1.dll (495), OpenSSL 1.1.1w;
  WHITELIST — 1446 функций справочника ViPNet OSSL 5.6.

Пересборка словарей (нужен pdftotext из poppler):
  python vipnet_ossl_whitelist.py --rebuild-data --crypto <libcrypto.dll>
      --ssl <libssl.dll> --pdf "<справочник>.pdf"

ОГРАНИЧЕНИЯ
-----------
  * Учитываются только динамические импорты: статически слинкованный OSSL
    и вызовы через указатели на функции в таблице импорта не видны.
  * Макросы (например, BIO_eof) не импортируются и в отчёт не попадают.
  * Имена нормализуются: снимаются __imp_, версия символа ELF
    (SSL_new@OPENSSL_1_1_0) и stdcall-суффикс @N.

ТРЕБОВАНИЯ
----------
  Python 3.9+ с tkinter (стандартная сборка для Windows).
  Сторонние пакеты не нужны. IDA нужна только для баз без .export.json.
