### 2. `diff_worker.py` — глобальный прогресс и статус пар

**Новые сигналы:**
```python
global_progress_updated = Signal(int, int, str)  # (step, total_steps, description)
pair_status_updated = Signal(str, str, str)       # (rel_key, engine, status)
```

**Переработка `run()`:**
- `total_steps = len(all_pairs) × 3`
- Счётчик `self._global_step` под локом, инкремент при завершении пары в любой фазе
- Emit `global_progress_updated(step, total_steps, "BinDiff — Экспорт из БД")` и т.д.

**Расширение `_run_pass_with_progress`:**
```python
def _run_pass_with_progress(self, stage_name, process_func, pairs, total,
                             engine=None, status_text="", status_done="✓"):
```
- `engine`: "bindiff"/"diaphora"/None (None = оба движка)
- Перед запуском: emit `pair_status_updated(r, engine, status_text)` для всех пар
- При завершении пары: emit `pair_status_updated(r, engine, status_done)` + инкремент глобального шага + `global_progress_updated`

**Эмиссия по фазам:**

| Фаза | engine | status_text → ✓ |
|------|--------|-----------------|
| BinDiff | "bindiff" | "Экспорт из БД" → "✓"/"✗" |
| Diaphora | "diaphora" | "Экспорт из БД" → "✓"/"✗" |
| Post | None | "Пост-анализ" → "✓"/"✗" |
| Report | None | "Генерация HTML" → "✓"/"✗" |

Движок не выбран → колонка "—", сигнал не эмитится.

**`_generate_reports` — добавление прогресса:**
- Перед циклом: emit `pair_status_updated` с "Генерация HTML" для всех пар
- В цикле: emit `pair_status_updated` + `global_progress_updated` при каждой сгенерённой паре
