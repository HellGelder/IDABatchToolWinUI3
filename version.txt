IDA BATCH TOOL (WinUI) — журнал версий сборки
==============================================
Формат записи: версия / дата / что изменилось.
Версия в свойствах exe должна совпадать с последней записью
(IDABatchToolWinUI.csproj: Version / FileVersion, make-portable.ps1: лончер).

1.0.0.7 / 2026-10-07
  Исправлено:
  - подвкладка «Git-сравнение»: поля путей (левая/правая директории,
    папка результата) выровнены по одной вертикали — минимальная ширина
    подписи перенесена на колонку грида (ColumnDefinition MinWidth),
    поля «Исключить» и «Строк контекста» выровнены в ту же линию
  - подвкладка «Git-сравнение»: журнал выполнения и замещающий текст
    переведены на общий шрифт приложения (убран моноширинный Consolas)

1.0.0.6 / 2026-10-06
  Добавлено:
  - вкладка «Сравнение» разделена на подвкладки «Бинарное сравнение» и
    «Git-сравнение»
  - подвкладка «Git-сравнение»: текстовый дифф двух директорий с исходниками
    в единый unified diff в стиле «git diff --no-index --no-prefix»
    (changes.diff в выбранной папке результата, журнал changes.diff.log).
    Реализовано нативно на C# (DirectoriesDiffService, алгоритм Myers):
    рекурсивный обход с glob-исключениями, определение бинарных файлов,
    нормализация EOL, распознавание BOM, настройка строк контекста;
    вывод сверен с оригинальным скриптом diff_gui.py (исполнение 1) —
    результат байт-в-байт идентичен

1.0.0.5 / 2026-10-06
  Изменено:
  - при выборе максимального числа потоков IDA (по числу логических
    процессоров) на вкладках «Анализ ПО» и «Анализ СФ» появляется инфобар
    с предупреждением о возможной высокой загрузке процессора и снижении
    отклика системы во время анализа; при уменьшении ползунка — скрывается
  - подсказка у «Включить псевдокод в JSON-экспорт»: исправлено нажатие
    (обработчик был подключён дважды — в XAML и в конструкторе, тогл
    срабатывал дважды и не открывал окно); цель TeachingTip назначается
    из кода
  - вкладка «Сравнение»: вместо всплывающей подсказки у «Только BinDiff» —
    информационная кнопка «i» (наведение/нажатие), как у настройки
    псевдокода; убран сдвиг подписи радиокнопок относительно кружка
    (причина — кастомный Padding, как на «Анализе СФ» ранее)
  - вкладка «Анализ СФ»: чекбокс «Включить псевдокод в JSON-экспорт»
    удалён — СФ-отчёты псевдокод не используют, экспорт всегда без него;
    ползунок потоков IDA перемещён на освободившееся место

1.0.0.4 / 2026-10-06
  Изменено:
  - ползунок «Потоков IDA» (вкладки «Анализ ПО» и «Анализ СФ»): по умолчанию
    и по максимуму — число логических процессоров машины; в config.yaml
    max_ida: 0 теперь означает «авто»
  - установка недостающего программного окружения (встроенный Python,
    jinja2/requests) выполняется тихо, без консольных окон; в диалоге
    установки кнопка «Установить автоматически» на время установки
    показывает прогрессринг, закрытие диалога блокируется; вывод установщика
    пишется в install-prereqs.log рядом со скриптом
  - добавлены подсказки: информационная кнопка «i» у настройки «Включить
    псевдокод в JSON-экспорт» (наведение — краткая подсказка, нажатие —
    подробная); подсказка у движка BinDiff на вкладке «Сравнение» — при
    выборе BinDiff пары со схожестью менее 99% всё равно проходят доанализ

1.0.0.3 / 2026-10-06
  Добавлено:
  - описания модулей, ранее показывавшихся как «Неопознанный модуль»:
    imm32 — Input Method Manager (менеджер методов ввода, системная
    библиотека ОС); winscard — Windows Smart Card API (ресурсный менеджер
    смарт-карт); tmdrv32/tmdrv64 — СКЗИ «Аккорд» (ОКБ САПР), драйвер
    доверенной загрузки и аппаратного ДСЧ — отнесён к стороннему ПО,
    категория «Криптография и безопасность»

1.0.0.2 / 2026-10-06
  Исправлено:
  - ошибка запуска генерации HTML-отчётов «имя файла или его расширение
    имеет слишком большую длину» на больших входных каталогах: список
    JSON-экспортов передавался мосту одной строкой в аргументе --json-paths
    и превышал лимит командной строки Windows (~32 КБ). Список теперь
    передаётся через временный файл-ответку (--json-paths-file), старый
    способ оставлен как запасной. Покрывает вкладки «Анализ ПО»,
    «Анализ СФ» и «Сравнение»

1.0.0.1 / 2026-10-05
  Добавлено:
  - проверка Python-окружения при запуске: если интерпретатор или пакеты
    jinja2/requests не найдены, появляется окно со списком отсутствующего
    и предложением автоматической установки; при полном окружении ничего
    не показывается
  - install-prereqs.ps1 в корне поставки: скачивает встроенный Python и
    ставит пакеты в app\Tools\Python (без прав администратора)
  - имя архива поставки теперь с версией: IDABatchToolWinUI-<версия>.zip
  - make-portable.ps1 встраивает Tools\Python из проекта, если он есть

1.0.0.0 / 2026-10-05
